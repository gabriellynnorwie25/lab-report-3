# Scholarship Advisory System 🎓

A web-based Scholarship Advisory System developed using Python and Streamlit for a university scholarship committee.

This system uses a rule-based approach to evaluate students' scholarship eligibility based on their CGPA, family income, co-curricular score, and disciplinary records.

### Features
- Applicant information input
- JSON-based scholarship rules
- Rule-based inference engine
- Priority-based decision-making
- Scholarship eligibility results
- Evaluation history
- CSV download

### Technologies Used
- Python
- Streamlit
- Pandas
- JSON

### How to Run

1. Install the required libraries:

   ```bash
   pip install streamlit pandas
   ```

2. Run the application:

   ```bash
   streamlit run app.py
   ```

3. Open `http://localhost:8501` in your browser.
